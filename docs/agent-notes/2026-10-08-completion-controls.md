# 补齐入口与可选上下文

输入框入口仅显示图标。悬浮框复用公开 Menu、MenuItemButton 和 Tooltip；提供商与模型在同一菜单中切换列表。齿轮打开高级设置 Modal。未导入宿主内部 ModelSelect，原会话模型状态独立保存。

当前草稿是必需的补齐输入。会话与剪贴板参考由独立布尔设置控制，默认关闭。Host 从当前 Session 的 deriveMessages 读取最近用户消息和助手正文，只提取 text 块，排除系统、开发者、工具及非用户来源的上下文消息。先限制条数，再从最新消息往前分配字符预算。

剪贴板读取只能由用户点击触发。文本存在 Client 页面内的临时 store，取消勾选后不发送；刷新或卸载清除，不写入 settings。Host 在参考开关关闭时丢弃客户端传来的剪贴板。已选择并实际发送的上下文与提示词作为 input/completion-request 记录，保持可重建，不进入主会话 surface。

草稿编辑器与接受/撤销实现没有修改。验证范围包含可选上下文关闭时不发送、历史条数与字符限制、图片和工具排除、自定义提示词、无效配置拒绝以及浏览器图标、浮层、齿轮和模型列表交互。

本轮 Rabi 状态查询没有返回可用地址；沿用当前会话已确认背景，并以插件源码、宿主公开接口和实际 profile 验证实现。

高级设置使用原生 Modal 的固定 footer。480px 及以下的视口把数字设置改为单列；表单行允许收缩，内容区独立滚动。浏览器验收覆盖桌面和 380px 手机宽度，检查横向溢出和底部按钮。
